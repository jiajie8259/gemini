品牌核心觀念

企業識別系統 (CI) 與標誌 LOGO 設計原理

企業識別系統 (Corporate Identity, CI) 旨在落實企業自我同一化，透過教育、明星化策略提升 brand 大眾印象。其由三大核心識別板塊架構而成：

三大識別體系 原文對應 實質定義與落實範疇
MI (理念識別) Mind Identity 企業經營理念、品質精神、品牌哲學。（CI 系統的核心原動力與靈魂、非視覺性）
BI (行為識別) Behavior Identity 員工教育、禮貌儀表、服務態度、工作規範。對外舉凡公益活動、文化推廣等。（非視覺性的動態實踐）
VI (視覺識別) Visual Identity 視覺整體系統，分為基本系統（標誌、字體、主色）與應用系統（名片、信紙、招牌等）。

LOGO 靜態識別設計的三大黃金原則

「好看只是基本分，更重要的是品牌理念與精神的準確傳遞。」

PRINCIPLE 01

① 準確性

設計造型必須能精準傳達品牌的行業屬性，避免語意混淆。

PRINCIPLE 02

② 關聯性

設計符號與企業的主體商品、品牌名稱之間應具備強烈邏輯性。

PRINCIPLE 03

③ 獨特性

造型輪廓需具備極佳辨識度，在競品市場中不易被抄襲混淆。

色彩警語： LOGO色彩不可隨意變更。色彩定義不佳會直接影響完稿與後續印刷製程的呈現。

Photoshop 介面重設、新增檔案與色彩模式

🛠️ 軟體介面救急與參數設定

  • 工作區還原：選單欄選擇 視窗 → 工作區 → 重設基本功能（Reset Essentials）即可一鍵復原消失的面板。
  • 屬性列（Options Bar）：當前啟用的工具，其對應的調節屬性、數值，會即時聯動顯示於最頂部上列屬性面板中。
  • 新增檔案規格 (Ctrl + N)：
    • 國際標準紙張：如 A4 規格。
    • 解析度：印刷設定在 300 dpi 以上 列印才會細緻；網頁設定 72 dpi ~ 150 dpi。
    • 色彩模式：設計可先採用 RGB (三原色) 以啟用完整濾鏡，印刷完稿時再行轉為 CMYK (四色)。

畫布縮放快捷操作

  • 按住 Alt + 滑鼠滾輪：向上滾動放大，向下滾動縮小。

  • 搭配控制：可使用導覽器（Navigator）面板無損調整檢視百分比。

筆刷設定、圖層堆疊管理與歷史記錄

筆刷工具核心規範

  • 筆刷尺寸調整快捷鍵：
    • 放大：鍵盤右中括號 ]
    • 縮小：鍵盤左中括號 [
  • ⚠️ 注意：若系統處於「中文輸入法」狀態下，筆刷縮放快捷鍵會失效。請切換回英文輸入法。
  • 超色域警告：若檢色器內出現「三角形驚嘆號」代表此色彩在實際 CMYK 列印時會失真、印不出來。

圖層面板操控學

  • 圖層為 Photoshop 的心臟。最上方的圖層會完全遮蓋下方的圖層。
  • 分層繪製優勢：物件分離後，您可以任意單獨移動、新增、合併圖層。若畫錯時，可單獨拿橡皮擦工具塗改，絕不破壞其餘圖層底色。
  • 背景圖層通常鎖定，可使用油漆桶工具倒入底色.
  • 新增圖層位置：點擊新增後，新圖層必定產生在當前所選圖層的「正上方」。

歷史記錄與拷貝

  • 歷史記錄面板預設最多可紀錄 20 步 操作步驟。
  • 做錯時，可在面板中點選「往前（上一步）」恢復。
  • 點選歷史記錄面板下方的「相機」圖示可以建立快照（Snapshot），方便做下一個大膽嘗試，失敗時能一鍵退回。
  • 拷貝貼上基本快捷鍵：
    • 選取：可選取方形或圓形區域.
    • 取消選取：Ctrl + D
    • 拷貝：Ctrl + C
    • 貼上：Ctrl + V

選取與去背

套索工具家族、魔術棒去背與調整邊緣

各式選取與去背工具

  • 一般套索工具 (L)：滑鼠按住自由塗畫，手寫形能圈選起要保留的圖形。
  • 多邊形套索工具：點對點直線圈選，適合硬質、幾何、多邊形物體去背。
  • 磁性套索工具：滑鼠游標拖移，會自動感應、辨識並吸附在對比強烈的色彩邊緣線上（極常用）。
  • 魔術棒工具 (W)：點選特定像素，會自動將相鄰且相同或相近顏色的背景一次選取，去背底色好用。
  • 容許度 (Tolerance)：調整魔術棒數值，可變更色彩選取寬度。預設數值一般不太會大範圍異動。

選取區加減運算與邊緣微調

➕ 選區相加 (聯集)

按住 Shift，可調整選取範圍不斷變大、合併新選區。

➖ 選區相減 (差集)

按住 Alt，可扣除重複或不要的選區範圍。

屬性列：調整邊緣（Refine Edge）

此控制面板能調整選取區的線條。「平滑」能將鋸齒變得滑順；「羽化」（Feather）會使邊緣變霧、產生漸變融合感而不顯得模糊突兀；「內縮 / 外擴」可手動微調去背邊界。

防手震修正：選取途中點錯，點擊 Del 鍵可刪除上一個錨點。按 ESC 鍵可全部取消選取。

漸層與光影

3/22 下午 漸層工具拉線與落地陰影製作

專案規格

寬 800 Pixels / 高 600 Pixels / 解析度 72 dpi / RGB模式 / 背景透明

漸層工具與打光效果

  • 漸層拉線技術：拉一條引導線即可套用色彩。若先將圖片縮小，將線由左往右「跨過畫布拉得極長」，漸層轉移效果會更淡、更自然。
  • 打燈效果 (放射狀)：
    • 新增圖層，選取前景色至透明漸層.
    • 屬性列選擇「放射性漸層」，由物體中心往外拉產生光圈。
    • 把該打燈圖層往下拖移到倒數第二個位置（主角圖層的正下方），光效就會呈現於主角背景。

逼真陰影 (Shadow) 製作

光效有了，還需要陰影。傳統作法是直接用深色筆刷刷抹，但專業手法需要藉由「變形工具」進行無損拉伸控制：

物體與其受光的變形壓扁影子

  1. 新增圖層，選取合適顏色（一般採用深色或筆刷取樣環境色）。
  2. 複製物體（圖層），點選 Ctrl + T 進行自由變形。
  3. 將控制點往下壓扁，使其變形呈落於地面之形狀。
  4. 在圖層面板中調降其不透明度（Opacity），使影子呈自然的半透落塵光感。

筆型與向量

向量筆型工具 (Pen Tool)、細部修飾與變形

筆型工具 (P) 核心觀念

筆型工具是用於描繪高難度幾何與流暢弧線（去背或繪製插圖）的向量級工具。其不會隨影像放大而模糊，是非像素點陣圖特性。

  • 屬性列選擇：可切換成「路徑」或「形狀」。若選擇「形狀」，在繪製閉合圖形後，內部會自動填入屬性欄所選的顏色。
  • 修飾與控制雙箭頭：
    • 路徑選取工具（黑箭頭）：點選並搬移整組向量框與圖案。
    • 直接選取工具（白箭頭）：用於點選單個「錨點（Anchor Point）」進行單點把手調整（控制把手只有在選到點時才會顯現）。
  • ⚠️ 弧形調控：若要拉出完美的弧形，必須在錨點處點著滑鼠不放，並朝「同一個方向拖拉」把手控制線，方能控制膨脹的凹凸方向。

各式微調與修飾工具

加深 / 減淡工具

針對照片區域進行加深（例如：加深眉毛、眼睛、唇角輪廓）與局部調亮。

海綿與模糊工具

海綿可改變局部飽和度。模糊工具可將背景虛化，顯現出突出的主體。

💡 自由變形比例規則 (Ctrl + T)：
進行縮放編輯修改時，務必按住 Shift 鍵 以維持原長寬比例。一般只能等比例縮小，因放大點陣圖檔會產生嚴重馬賽克與失真。
⚠️ 斷線重置技巧：繪製複雜路徑時，若中途滑鼠不小心點到外部圖層而「斷線」，請拿筆型工具點擊最後一個動作的錨點（指標旁出現一條鍊條符號）即可完美接續。

字型排版與文字方塊操控

  • 段落文字框：輸入詳細說明（長文字）時，務必拿文字工具 (T) 按住拖曳出一個「文字方塊框」，再將文字貼入。這能實現文字自動換行與寬度對齊，絕不會超出畫布。

    • 按住 空白鍵：滑鼠變為手掌工具，可在放大時隨意拖動畫面。
    • 選單 檢視 → 勾選 靠齊（Snap）以方便拉動引導線。
    • 移動引導線：微調精確度，每次移動鍵盤方向鍵可推移 0.10 cm。

漸層進階

漸層編輯器進階調校、雜訊與圖層混合模式

漸層編輯器 (Gradient Editor)

新圖層可自選色彩或新增色阻。雙擊漸層色條，上方滑桿可調節透明度（Opacity）；下方滑桿可決定顏色阻尼點。

🎨 雜訊與粗糙度漸層：

將漸層類型由「純色」切換為「雜訊」，並將「粗糙度」設定在 70% 以上。此時畫面會顯現高對比、如微粒子般極清亮的砂礫質感。勾選「限制顏色」與「加入透明度」能隨機變更出色彩斑斕的裝氣、流體科幻質感。

圖層混合模式 (Blend Mode)

用於決定上下兩個圖層如何融合呈色。常見的有：「色彩增值」（變暗，去白留黑）、「濾色」（變亮，去黑留白）與「覆蓋」（加強光影對比）。

💡 唯美聚光燈 (Spotlight) 效果製作：
  1. 新開圖層，拿白色霧狀大軟筆刷在畫布正中央點一下。
  2. 使用自由變形將該白色光點往左右拉伸、壓扁.
  3. 將該圖層混合模式設定為「覆蓋」或「柔光」，即能在背景打出漂亮的立體聚光燈。

液化與樣式

液化濾鏡修容、圖層樣式與水滴質感實作

液化濾鏡與修形 (Ctrl + Shift + X)

「液化」是人像修圖的絕對利器。可以用滑鼠揉捏、修飾照片，例如讓下巴曲線變自然、微調眼神、縮小臉頰等。

⭐ 圖層樣式（Layer Style）開啟三方法：
  • 雙擊圖層面板空白處（注意不能雙擊到文字名稱，否則會變更名稱）。
  • 點擊圖層面板底部的 fx 快捷鍵圖標。
  • 選單欄選擇：圖層 → 圖層樣式。

* 核心秘密：「不透明度（Opacity）」降低會讓整個圖層含樣式變透明；而「填滿（Fill）」降至 0% 則會隱藏本體填色，只保留立體的圖層外觀樣式效果。

立體真實水滴效果合成實作

Fill 0%
  1. 基本塑形：新增一空白圖層，填充黑色，使用液化濾鏡隨意扭拉、捏揉出不規則的自然水滴塊狀。
  2. 斜角與浮雕：樣式設定中調整細節尺寸，使其表面呈現凸透亮面的高光折射。
  3. 陰影：加強色彩增值模式的下墜陰影，調低不透明度，使投影柔和。
  4. 筆畫與內光暈：增加邊界通透度。筆畫要在特定空白處才能設定數值；內發光選擇與背景接近的色彩。
  5. 隱藏本底色：最後將圖層面版的「填滿（Fill）」調低至 0%，黑底消失，通透、立體的真實水滴瞬間成形。

圓角矩形與扭曲

圓角矩形半徑、波形濾鏡與背光漸層

圓角矩形與波形扭曲

  • 圓角矩形工具：屬性列可即時調整圓角半徑數值。數值越大，角形越圓滑。
  • 波形效果模擬水滴流動：

合版印刷

3/15 下午 合版印刷四大黃金法則與局部上光檔案

合版印刷為多個客戶的卡片合併在一大張紙上共用版費列印，必須嚴格遵守以下物理規範，否則極易產生退件大色差：

① 總油墨量不得超過 200%

大面積色塊在 CMYK 四色套色時，四個顏色的總和絕對不能超過 200% (例如 `C:80, M:60, Y:60, K:10` = 210% 即超標)。

後果：總量過高會使油墨堆積、久乾不透，在裁切與運輸疊放時極易引發嚴重的「背印疊色與黏紙毀損」。

② 純黑中文字 K100 限制

小中文字型、電話等細節文字，CMYK 的 C、M、Y 三色務必設為 `0%`，僅單獨在 K 填入 100%。

原因：印刷機四色套印會有微小物理偏位，若文字用四色混色黑（四色黑）印刷，印出會產生模糊、重影與嚴重的七彩毛邊。

③ 大面積特黑 (Rich Black) 配方

如果是大面積的純黑背景，若只單獨填 K100，印出會呈現灰白無光感。

配方：可改設為 C:40, M:0, Y:0, K:100。利用少許青色打底，能使純黑底色呈現厚實、飽滿的特黑亮面質感。

④ 局部上光 (Varnish) 完稿黑版

製作局部亮面光阻效果檔案：

操作：將需要上亮面的字體、圖層複製一份。套用顏色覆蓋 → 將其強制改為純黑色 K100。新增一空白圖層，倒入白色。此白底純黑字檔案即為局部光阻黑版，另存成 TIFF 格式與原圖一同出貨印刷。

放射漸層拖拉技巧與避坑

放射性漸層繪製背景時（中間白、外圍黑），滑鼠必須由貼圖中心點起筆、垂直水平往外拉。

利用色板黑白兩色的高對比度，可以實現完美的髮絲去背：

  1. 點開色板面板，點選紅、綠、藍色版，尋找一張明暗、輪廓對比最強烈的色版。
  2. 複製該色版 → 按 Ctrl + L (色階)，強行將高光拉亮、陰影拉暗，使其呈高強度黑白對比。
  3. 拿黑色筆刷將不需要去背的雜點塗黑，主體塗白。
  4. 按著 Ctrl 點選該色版縮圖以載入其選取範圍。
  5. 回到彩色 RGB，即可精緻地拷貝去背。

紙張材質覆蓋

紙質紋理材質 (Paper Texture) 疊加、去雜點與高斯背景

紙張材質 (Paper Texture) 疊加技法

若要讓畫面或字體產生復古、手繪 or 精緻的高級紙張顆粒質感：

操作：上網下載免費的高解析度 Paper Texture (材質檔) → 在 Photoshop 中開啟。

快捷流程：按 Ctrl + A (全選) → Ctrl + C (複製)。回到海報的羅馬主畫面，按 Ctrl + V 貼上。按 Ctrl + T 調整覆蓋滿版。最後將該圖層混合模式設定為「色彩增值」或「覆蓋」，即可將紙張纖維、砂質紋理完美融合於原照片中。

精緻背景與球體打光

  • 背景高斯虛化：複製背景圖層，套用高斯模糊，並配合快速遮色片，將眼神五官遮蔽。
  • 暗部雜點噪點注入：新開空白圖層倒入黑漆，配合濾鏡噪點，降低透明度，即可消除漸層的大塊色階斷裂，使圖片過渡平滑。
  • 球體與十字架打光：新開圖層 → 選擇黃色或青色 → 拿霧狀大軟筆刷，在混合模式下調低透明度，使球體產生高反光的金屬球體與十字架神聖光澤。

動作面板自動批次化

當手上有幾百張照片要進行同等縮小尺寸、調色或去背時，使用手動調整會耗費大量時間。可啟用自動「動作（Actions）」：

  1. 選單選擇：視窗 → 勾選開啟 動作 面板。
  2. 點擊面板下方的新建動作，面板上會亮起「紅色錄製鈕（Record）」，此時系統會忠實錄製您的每一步操作。
  3. 開始編輯：調整影像大小、套用曲線調色、最後另存新檔。
  4. 完成後，按下「停止鍵（方形按鈕）」。批次流程即錄製完成。
  5. 開啟其餘照片，點選該動作並按「播放（三角形按鈕）」，數秒內即自動執行完畢。

DeviantArt 動作包資源載入

推薦歐美最大設計交流社群網站：www.deviantart.com。

🚀 載入與應用大師級調色動作包：
  • 搜尋「Photoshop Actions」或 PSD 動作。
  • 點選 Popular All Time (經典熱門)，將喜歡的效果 Download 下載。
  • 解壓縮下載後的文件。
  • 在 Photoshop 動作面板空白處點右鍵 → 選擇「載入動作」，載入已解壓之檔案。即可免費套用極限調色動作。

液化與去背

液化微調膨脹、頭髮髮絲極致去背與智慧型偵測

液化細部工具調校身材

在液化選單中，除了單純揉捏扭拉外，還可進行局部膨脹與收縮微調：

  • 膨脹工具：點擊滑鼠可局部放大（常用於放大胸部、讓眼睛變大）。
  • 縮小 (重組) 工具：點擊滑鼠可局部收縮（常用於修飾多餘贅肉、收細手臂、細大腿）。
  • 連結色：點選連結，調整時才不會扭曲、動到你已畫好的邊界範圍。
  • 解凍遮色片 / 凍結工具：按右鍵可凍結部位，保護圖案不變形；完成後按解凍即可。

頭髮髮絲極致精密去背 (Select & Mask)

去背最難之處在於散亂不齊、有環境底色的頭髮。精密步驟：

  1. 拿快速選取工具粗略選起人像，貼到背景圖片。
  2. 點擊上列屬性列之「調整邊緣」（選取並遮住）。
  3. 邊緣偵測：勾選「智慧型半徑」，調高像素值。
  4. 拿起調整邊緣筆刷，在頭髮散亂、夾雜背景色的細毛邊緣細刷，系統會自動智慧清除邊界背景色。
  5. 最重要一步：勾選底部的「淨化顏色（Decontaminate Colors）」，確定。
  6. 系統會自動產生一個帶有遮色片的新圖層。對遮色片點擊右鍵 → 套用圖層遮色片，即可得到完美去背的人像。

🏀 運動大片級海報製作步驟

規格：寬 950 Pixels / 高 500 Pixels / 解析度 72 dpi / 背景透明。

  1. 新檔案，填入純黑色。

網頁排版

非破壞性色彩平衡調整圖層與網頁版面警語

非破壞性調整圖層

在圖層面板底部的半圓圖示（調整圖層）點選新增：色彩平衡、曲線等調整圖層。

✨ 調整圖層三大優勢：
  • 不需要合併圖層，絕不破壞原圖，隨時雙擊可重複微調、更改顏色。
  • 只會對位於「它下方」的所有圖層產生色彩變更，它上方的圖層完全不受干擾影響。
  • 色彩平衡中：可針對陰影部、中間調、高光進行細部分離控制。

網頁設計字型向量警語 (重要！)

  • 網頁中有文字、表格或細緻的中文字，請務必在 Illustrator (AI) 向量軟體中進行完稿排版，而非直接在 Photoshop 中寫字。
  • 原因：Photoshop 排版後的文字與表格一旦執行影像平面化或存成點陣圖片，文字就會完全像素化，以後就再也無法更改文字字元內容。
  • 置入火箭隊 LOGO 圖，貼在 Jeremy Lin 旁。

動態網頁

網頁 GIF 動畫時間軸面板與永遠重複循環

時間軸 (Timeline) 製作動態廣告

Photoshop 不僅能處理靜態海報，更內建了製作動態 Banner 廣告的動畫功能：

  1. 點選選單：視窗 → 勾選 時間軸，啟用網頁動畫編輯器。
  2. 點選「建立格動畫」。
  3. 影格複製：在時間軸面版下方點擊新建複製影格（例如複製出 3 個影格）。
  4. 在不同的影格中，於圖層面板上開啟或關閉特定眼睛（控制物件閃爍）、或利用移動工具變更字體與瓶身位置（控制物件飄移）。

GIF 循環與動態匯出

在每個影格下方，您可以點擊微調停留延遲秒數（例如：0.2秒）。

⭐ 循環模式與網頁儲存：
  • 時間軸底部的循環設定，務必下拉選擇「永遠」（Forever）。這樣動畫在網頁中開啟時才會無限循環播放，不致於播完一次就停下。
  • 選擇選單：匯出 → 儲存為網頁用 (舊版)。格式選擇 GIF 格式，按下存檔。即可完成網頁專用動態廣告 Banner。
